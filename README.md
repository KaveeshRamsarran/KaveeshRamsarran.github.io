# Jai Ramsarran · Portfolio

Personal site for Jai (Kaveesh Ramsarran), a software developer working across simulation and game systems, applied machine learning and front-end engineering.

The hero has a live, interactive cut-down build of the EarthPlay simulation engine. Below it are twelve projects with technical breakdowns, a stack index that links each tool to the projects that use it, a timeline and contact details.

Live at **https://kaveeshramsarran.github.io/**

It's a single static `index.html` written by hand, with no framework and no build step. Edit it and push to `main` to update the site.
